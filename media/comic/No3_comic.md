# The Mentorship Protocol: Teach the Network Like a Good Mentor — Comic / Deck Script

**LOGLINE:** Teach the network like a good mentor teaches a student.
**THE ONE IDEA:** Strong nodes hand small 'grafts' of skill to weaker ones at save-points, and the network improves as a team.
**PANELS:** 14 · **PALETTE ACCENT:** gold · **GUIDE-MOTIF:** Pip (a single warm-amber node of light)

> Art notes: every ART PROMPT already ends with the shared STYLE TOKEN + NEGATIVE TOKEN from the
> Series Bible §8. Pip is described identically each time so it stays on-model. No text baked into art.
> Signature motif this issue: the **graft handoff** — a bright node grows a small glowing graft and
> hands it to a dimmer node, which brightens. The **Central Oracle** is the pulsing checkpoint ring.
