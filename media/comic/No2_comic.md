# Paraconsistent Consensus: A Network That Treats Disagreement as Information — Comic / Deck Script

**LOGLINE:** What if a network treated disagreement as information instead of noise?
**THE ONE IDEA:** Keep contradictions instead of averaging them away, so a router can use them.
**PANELS:** 14 · **PALETTE ACCENT:** magenta · **GUIDE-MOTIF:** Pip (a single warm-amber node of light)

> Art notes: every ART PROMPT already ends with the shared STYLE TOKEN + NEGATIVE TOKEN from the
> Series Bible §8. Pip is described identically each time so it stays on-model. The signature image
> of this chapter is the **gold+magenta split node** (Belnap "both") set against the bad thing:
> **many colors blurring into flat grey** (averaging). No text baked into art.

## Producer notes
- **Panel count:** 15 beats (cover + 13 story panels + back cover), within the bible's 12–16 range; the doubled honesty beat (11 and 12) is intentional and non-negotiable.
- **Runtime as a deck:** at ~8–10 seconds/panel this reads as a ~2:15 auto-advancing picture-book; pair with the screenplay VO for a fuller cut.
- **Reflow to 9:16:** stack caption under art; keep Pip centered; panels 4, 7, 13 are the "wow" beats — give them the most motion if animated.
- **Signature contrast:** the whole chapter lives on one visual argument — the **gold+magenta split node** (keep the disagreement) versus **colors blurring to flat grey** (averaging). Never blend the split node; it must always read as two colors held apart.
- **Consistency:** reuse the exact Pip phrase ("a single small warm-amber node of light, soft bloom, no face") in every prompt so the character never drifts.
- **Facts check:** the two honesty beats (panels 11, 12) trace to Paper II — the four-valued logic is an execution-layer/learning-daemon layer invoked *at* checkpoints, not a change to the classical finality rule (§4.1); the aggregation kernel is TLA+ machine-checked (§3.3) while full coupled-loop convergence is an explicit conjecture, untested at network scale (§7.2, §8). Panel 9 "every 50 blocks" and the four Belnap labels trace to the paper. Do not add numbers the paper doesn't support.
