# The Memetic Money Portal: Letting Value Leave Without Selling the Fuel — Comic / Deck Script

**LOGLINE:** How value leaves the network without selling out the fuel that runs it.
**THE ONE IDEA:** Separate the instrument that brings in outside liquidity from the gas token, so raising money doesn't dilute the fuel. Built as a wrapped token plus a contracted market-maker, not the NFT bridge first imagined.
**PANELS:** 15 · **PALETTE ACCENT:** gold · **GUIDE-MOTIF:** Pip (a single warm-amber node of light)

> Art notes: every ART PROMPT ends with the shared STYLE TOKEN + NEGATIVE TOKEN from the Series Bible §8.
> Pip is described identically each time so it stays on-model. No text baked into art. Value is always
> shown as light that flows, never coins or dollar signs (Bible §4).
>
> New motifs introduced here (not yet in the dictionary — add on adoption):
> - **Wrapped shell** — a mote of gold light held inside a thin, clear protective shell; the light moves, the shell keeps it safe.
> - **Crossed-out bridge** — a span drawn across a gap, then dimmed and struck through; a design set aside, not a thing that exists.
> - **Stall-keeper** — a single steady node that quietly balances two pans of light so a price stays level.
> - **Governance leash** — a thin cyan tether from the network to a hired node; it can be re-tied or cut.
