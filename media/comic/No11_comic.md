# NAT: A Mind With Labeled Rooms — Comic / Deck Script

**LOGLINE:** A mind with labeled rooms, so you can always see which room did the thinking.
**THE ONE IDEA:** Split the model into declared, named zones over a fixed layout, so every answer comes with a replayable record of which zones did the work — verifiable by construction, and (in the tests so far) doing more with the same number of parameters at small scale.
**PANELS:** 15 · **PALETTE ACCENT:** six-hue zone palette · **GUIDE-MOTIF:** Pip (a single warm-amber node of light)

> Art notes: every ART PROMPT ends with the shared STYLE TOKEN + NEGATIVE TOKEN from the Series Bible §8.
> Pip is described identically each time so it stays on-model. No text baked into art. The six named zones
> use the zone palette (§3): six distinct hues, each zone pulsing on its own beat. The provenance trace is a
> gold+cyan comet-trail (§4 dictionary). Honest scope caveats appear on Panels 11–12 as written.
