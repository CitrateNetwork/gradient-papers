## Producer notes
- **Runtime as a deck:** at ~6 seconds/panel this reads as a ~90-second auto-advancing trailer; pair with the No0 screenplay VO for the narrated cut.
- **This is the map, not a chapter.** Each paper gets exactly one panel and one hook. Resist deepening any single paper — that's what Papers I–XI are for. The job here is to make someone want to watch the other eleven.
- **Color discipline:** each paper keeps its spine accent (§9) so the region colors here match the individual pieces. Pip takes on each region's tint as it arrives, then returns to gold.
- **Honesty is structural (Panel 14):** built regions glow solid, proposed ones read as blueprints. The maturity tags in the captions (built / a practice / an idea, not built yet / inspiration / off by default) come straight from the papers' own status lines. Never upgrade a tag to sound further along.
- **Consistency:** reuse the exact Pip phrase ("a single small warm-amber node of light, soft bloom, no face") in every prompt so the character never drifts.
