# The Gradient Papers

A 12-paper research series (Papers I to XI plus a Series Index) on the ideas behind the
Citrate Network: a BlockDAG chain built for AI, paraconsistent consensus, verifiable
inference, the mentorship protocol, cooperative economics and NAT.

Published by **Citrate Inc.** Authors: **Larry Klosowski** and **Lauren Mendenhall**.

## Read

- `markdown/`: the source of truth, one file per paper (v3).
- `pdf/`: built PDFs.
- `arxiv/`: LaTeX sources (shared preamble, bibliography, one `.tex` per paper).
- `media/`: figures.

Claims are tagged **[Implemented]**, **[Specified]** or **[Theoretical]**, and implemented claims
point to the code on the Citrate testnet (chain 40204) so they can be checked.

## Critique welcome

These papers are public so they can be challenged. Open an issue for an error, a weak argument,
a missing citation or prior art we should credit; pull requests with corrections are welcome.

Licensing for reuse is still being decided by the authors; until then, quote and cite freely
for review and critique.
